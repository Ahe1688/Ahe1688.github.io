## v9.1 / v11.1 更新了什么（2026-11-03，两批修复）

针对用户反馈「默认源没有港澳台分类、找不到自定义源入口」，查明**两个根因**并全部修复：

**根因一：作者服务器优先（已停用）。** 此前版本（v5 起的设计）会先连作者官方服务器 `api.aliiptv.com`，服务器可达时 APP 一直用作者官方源（75 个频道、无港澳台、带 EPG/回看），我们自己的源和内置兜底**根本不生效**。
- 修复：停用作者服务器（config_url 改 127.0.0.1，并更换配置缓存 key 防止旧缓存顶掉新配置），主源切换为 `cdn.jsdelivr.net` 的每日验证 channels.json。

**根因二：自定义源入口被改名。** 设置弹窗里第三个标签页其实就是自定义源面板（含「本地导入」「网络连接导入 M3U/txt」），但被原作者改名为「手机助手」，且网络导入框预填的是被墙的 github.io 地址。
- 修复：标签改回「**自定义源**」；导入框预填 jsDelivr 的 live.m3u8 地址，按确认即可导入。

**其他**：内置兜底源升级为最新每日验证数据（280 频道含港澳台 18 频道）——即使完全断网，打开也有干净的央视/卫视/港澳台/地方台；与 v9/v11 同包名，**直接覆盖安装**。

**取舍说明**：停用作者服务器后，EPG 节目单和「可回看」功能不再可用（那是作者源私有协议提供的）；频道列表、源质量、更新频率由我们的每日流水线接管。

**用途：日常使用的最佳版本。**

- **每次冷启动自动拉取最新直播源**（每日由 GitHub Actions 自动更新），保证每次打开都是新源。
- **退出后零后台**：无定时任务、无开机广播、无后台刷新，省电。
- 频道：央视 / 卫视 / 港澳台 / 省市地方台，全部经过每日**存活过滤 + 播放级验证**（模拟播放器下载视频切片测速，剔除"列表活着但播不出画面"的源），快源排前。

## 两个版本的共同点

- 源全部来自本仓库每日自动流水线：抓取 6 个聚合源 → 只保留央视/卫视/地方台/港澳台（国外台剔除）→ 存活过滤 → 播放级验证测速 → 生成 `channels.json` 与 `live.m3u8`。
- 每天约北京时间 08:00~11:00 自动更新（jsDelivr 缓存约 12 小时，源更新会有最多半天的延迟，属正常）。
- 冻结版：已移除作者远程更新通道；不回连作者服务器。
