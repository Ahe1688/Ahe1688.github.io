## v9.1 / v11.1 更新了什么（2026-11-03）

针对用户反馈的两个问题（手机上默认源没有港澳台分类、手动配置源失败），根因是 **github.io 在部分国内网络被阻断**：APP 拉不到线上源 → 静默回退到内置兜底源（旧数据，无港澳台分类）；手动导入走的也是 github.io 域名 → 同样失败。v9.1/v11.1 修复：

1. **源地址改为国内可达的 jsDelivr 镜像**：
   - 默认源 `channels.json` → `https://cdn.jsdelivr.net/gh/Ahe1688/Ahe1688.github.io@main/channels.json`
   - M3U 导入预填 → `https://cdn.jsdelivr.net/gh/Ahe1688/Ahe1688.github.io@main/live.m3u8`
2. **内置兜底源升级为最新每日验证数据**（280 频道，含港澳台分类 18 频道），替代旧的 198 分类「省-运营商」数据——即使完全断网，打开也有干净的央视/卫视/港澳台/地方台。
3. 与 v9/v11 同包名，**直接覆盖安装即可**，无需卸载。

## 两个版本的共同点

- 源全部来自本仓库每日自动流水线：抓取 6 个聚合源 → 只保留央视/卫视/地方台/港澳台（国外台剔除）→ 存活过滤 → 播放级验证测速 → 生成 `channels.json` 与 `live.m3u8`。

- 冻结版：已移除作者远程更新通道；不回连作者服务器。
