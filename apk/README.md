## 两个版本的共同点

- 源全部来自本仓库每日自动流水线：抓取 6 个聚合源 → 只保留央视/卫视/地方台/港澳台（国外台剔除）→ 存活过滤 → 播放级验证测速 → 生成 `channels.json` 与 `live.m3u8`。
- 每天约北京时间 08:00~11:00 自动更新一次（GitHub 免费版调度有 1~3 小时延迟，属正常）。
- 冻结版：已移除作者远程更新通道，作者无法推送新版本重新上锁；不回连作者服务器。
- EPG 节目单：主流频道可能命中，地方台多数匹配不上（EPG 数据源 ID 体系差异），属正常现象。
